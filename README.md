# Agent HQ prototype

Bản xem thử giao diện "văn phòng agent" (Level 3 của dự án Agentic OS Claude Code). Một file `index.html`, mở là chạy.

- Cảnh 3D 4 phòng quanh quả cầu brain (Three.js), tab Office / Tasks / Calendar / Brain.
- Bấm phòng để mở panel; bấm agent để mở khung chat. Ô tìm `Ctrl+K`.
- **Toàn bộ dữ liệu là mẫu.** Chưa có agent thật nào chạy phía sau; gửi tin và Duyệt/Từ chối chỉ lưu trong trang đang mở.

Giao diện lấy cảm hứng từ ý tưởng "Agent HQ" của kênh YouTube @bekhruzbuilds. Đây là bản dựng lại bằng hình khối đơn giản, không dùng tài nguyên của kênh đó.
